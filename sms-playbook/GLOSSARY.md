# Glossary — the words we use (and the ones we killed)

> Goal: every term in the SMS system is one you can explain in a sentence. AI-coined jargon that
> snuck in (arsenal, altitude, hook-lever router) is renamed to plain English or cut. If a skill
> still uses a CUT word, that's a bug — fix it.
>
> **Aaman: this is the de-buzzwording sign-off. Change any definition you don't like — they're
> yours, not the framework's.**

---

## KEEP — core terms, plain meaning

| Term | Plain meaning |
|---|---|
| **Bite** | The "tell me more" feeling. The one thing a first text has to earn. |
| **The two bars** | Every text must clear both: **"this is real"** (believable result) and **"this is for me"** (relevant to them). |
| **Mechanism** | The "how we did it" line. Its job is curiosity, not extra proof. |
| **Result / proof anchor** | The headline outcome we lean on for credibility (named brand + number + timeframe). |
| **Relevance** | Something specific about *them* — their work, niche, or a real pain. The "for me" bar. |
| **Pattern** | A proven *shape* for a mechanism line (e.g. Contrarian, Plain-English). Lives in `pattern-library.md`, derived from real winners. |
| **Psychological lever** | The emotional frame of the text. We use **5**: FOMO, Unique, Curious, Timely, Helpful. (From your flowchart — this is the primary taxonomy.) |
| **What carries the bite** | For a given case study, is it the **mechanism**, the **result**, or **relevance** that does the heavy lifting? Decided by the offer + case strength. |
| **Slice** | When a case study has several wins/services, the **one** we choose to lead with in the text. |
| **Spread** | The set of draft variants a skill produces. We generate options to test — we don't pre-pick the winner. |
| **The without-X wrapper** | The "…without [the thing they assume is required]" clause. A sentence frame you bolt onto a result+mechanism — **not** a mechanism on its own. |
| **Sophistication** | How many similar pitches this buyer has already heard. High = they've seen it all (lead with something weird/specific); low = a plain strong result still lands. |
| **DBS** | The skill file structure: **D**irection (SKILL.md) · **B**lueprints (references/) · **S**olutions (scripts/). |

## The library is TWO-TIER (locked from the winners data)

The 17 tagged winners showed that **what carries** the text matters more than which mechanism
pattern it uses. So the library is split:

- **Tier 1 — what carries the text** (pick first): `case study / result` · `specificity / relevance`
  (often Clay-driven — proving you know exactly who they are) · `authority` (credibility byproduct —
  ex-Google, name-drops, case-study stacks; rides inside proof or mechanism, it is NOT a lever) ·
  `guarantee`.
- **Tier 2 — mechanism patterns** (only used when the *mechanism* is the carrier):

| Pattern | One-line |
|---|---|
| **Contrarian** | Name the boring default the whole category does, invert it. ("humor to make ads actually entertaining") |
| **High-level abstraction** | On a strong case, skip the tactics and name the *position* or *named method*. ("the go-to voice for AI defense", "signal-based outbound") |
| **Plain-English tactic** | Just say what you did, plainly, when the tactic is obviously desirable. **(Dominant pattern — absorbs most "named" tactics, incl. the old competitor-redirect.)** ("ranking them #1 on Google for X") |
| **Trigger / Timing** *(situational)* | Not what we do — *when*. ("at the exact moment a property floods") |
| **Risk-reversal (guarantee)** *(situational)* | Remove the risk. ("10 new appointments or you don't pay") |

## RENAMED — same idea, plain word now

| Old (buzzword) | New (what we say) |
|---|---|
| **Arsenal** | "What the case study gives you" / "the ammo you have." |
| **Altitude** | "Strong case → fly high (vague/no mechanism). Ordinary case → get specific." |
| **Carrying lever / hook-lever router** | "What carries the bite" (mechanism / result / relevance). |
| **Angle** (sms-draft's 8-item list) | Folded into the **5 psychological levers** + offer-frame. We don't keep a separate "angle" taxonomy — that was the 3-taxonomy mess. |
| **Offer-frame** | "When there's no mechanism and no outlier number — lean on scarcity / guarantee / referral framing." Kept as a concept, plainly named. |

## CUT — gone, do not use

| Removed | Why |
|---|---|
| **Hidden Misattribution** | Mislabeled and confusing. |
| **Belief-break** | Name didn't land ("I don't know what that means"). CUT — W7-style lines fold into Plain-English. |
| **Competitor-redirect** | Aaman: "it's just plain English." Folded into **Plain-English** (e.g. W11 Pirawna). |
| **Visual Theft / Inversion** | Too cute, and the winners don't support it as a standalone. |
| **offer-frame** (as a bucket) | Aaman: "don't put offer-frame when there's nothing — just put n/a, don't hallucinate." Use `n/a` when there's no mechanism; use `Risk-reversal` when a guarantee is the real move. |
| **Volume-as-mechanism** | "1,000 unpaid creators" alone isn't a mechanism — it never appears as one in a winner. Always pair a volume number with a structural move. |
| **Position Engineering / Named Methodology** (as separate patterns) | Merged into **High-level abstraction** — they're the same move (drop tactics, name the position/method). |
| **Flywheel / system (as a mechanism noun)** | Reads as agency-speak; never in a winner. |
