## The locked principles (also in `MEMORY.md` / memory files)

- **Co-create** judgment artifacts (strawman → he redlines); never finalize unilaterally.
- **Plain language, no AI buzzwords** (he rejects coined jargon; killed "arsenal/altitude/carrying-lever/bold").
- **Mechanism = a core pillar**, mined-and-sharpened (not lifted from the generic master sheet, not invented). Guardrail REFINED: a line needs one real anchor (mechanism / a Layer A wall / a status fact); implicit framings + positioning attribution are ALLOWED + flagged "defend on a call"; only anchored-to-nothing is killed.
- **Don't overfit to one client** — principles general, examples short + multi-offer, derive client-specifics from Layer A at runtime. (Caught me twice this session writing blanket rules from one instance.)
- **Skill refs operationalize, don't narrate** — checklists/tables/rubrics, one source per concept, cross-check vs winners.
- **Division of labor:** strategist-led, skill-assisted. The strategist owns the direction (lever, which objections) + the final pick; the skill floods, drafts, QA's.
- **Validate by RUNNING, not inspecting** (the big lesson — see below).

## What the GoFish run taught us (the core findings)

Aaman ran both skills on **GoFish / EZ Bombs (TikTok Shop, food-bev)** — the first real end-to-end run.

- **case-study-developer scored 5.5/10 and took ~5 hours.** Root cause: the skill was **passive, literal, low-volume** — it handed a thin "representative menu" and waited to be dragged through volume, status proofs, objection-handling, and implicit angles one turn at a time. It captured the *menu shape* but not the *strategist's proactive behavior*. **Why it shipped at 5.5 despite "good to go":** I declared it ready on **inspection** (builds cleanly, no buzzwords, refs resolve) and **never ran+graded it**. The evals tested *correctness* (guardrails), not *excellence*. → Fixed: objection spine (cross-ref Layer A pains+objections, weave implicitly, label the wall, show the assembled sentence), status/authority framing (from the master-sheet "other notable results"), generate-2-3-outcome-tiers-lead-with-strongest, go-heavy-on-implicit (separate from flagged inference-liberty), plain-over-clever, volume-then-cut + branch-the-service-lines, near-final-quality bar, inline-brainstorm-not-MD-dump. Then a de-overfit pass (made the GoFish-shaped "always halo/full-story" conditional; multi-offer examples).
- **sms-draft beat his human strategist (Fahad)** — ~8/10 copies — but with concrete bugs (QA gate not actually gating). → Fixed: QA gate **mandatory** + new catches (anatomy: mechanism welded to T1 never split to T2; no-two-questions; AI-cringe "no X no Y"; self-defeating disarmers; automated-FOMO statements; overclaim/halo must be flagged not stated); **propose proven openers** (don't default to "bit random"); richer/more-human **CTA variation**; **wordsmith-not-slot**; **report off-script** (discard fails with a reason, never ship broken or deviate silently). Pulled a "don't-assume-prospect-facts" rule (it came from context Aaman fed it, not the skill going rogue).
- **Honest caveat:** in this run, Aaman's manual hour on the mechanisms (case-study-developer) did the heavy lifting; sms-draft mostly assembled. And **GoFish was "lucky" — the mechanisms weren't hard to find.** A harder client (thin/commodity mechanism, e.g. SEO/GEO) is the real stress test.

## The discipline going forward (how it keeps getting better, not stuck at 5/10)

1. **Never declare ready on inspection — run and grade real output.**
2. **Bake the principle, never the instance.** Test before baking: *"would this still help a client with totally different ammo?"* If it only works with this client's variables, it's a patch, not a principle.
3. **Prove generalization on a DIFFERENT-shaped offer** before trusting a fix.
4. **Evals must test excellence** (did it flood / run the objection spine / go implicit / mine status), not just guardrails — across 2-3 offer shapes.
5. **Evergreen data loop** (later, w/ the engineer) = the compounding layer (winners/losers DB w/ embeddings — plan in `~/.claude/plans/`). Until then it's manual run→grade→generalize.
